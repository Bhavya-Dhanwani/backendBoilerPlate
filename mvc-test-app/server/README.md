# mvc-test-app

Production-ready Express backend generated using **create-backend-app**.

## Features

- **Language:** JavaScript
- **Module System:** CommonJS
- **Architecture:** MVC (Function Based)
- **Database:** MongoDB
- **Auth:** Enabled (Single Token)
- **Logger:** None
- **Swagger Documentation:** Disabled
- **Docker Support:** Disabled
- **Testing:** Disabled

## Getting Started

### 1. Environment Setup
Copy `.env.example` to `.env` and update the variables:
```bash
cp .env.example .env
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
